01

Training + change enablement

Learner 360 + New Student Portal

Audience / context
Faculty preparing for a changing learner and portal experience.
Problem
Platform features and workflows were evolving while faculty still needed operational clarity.
My contribution
Supported rollout through faculty operational training, project coordination, quick-reference resources, support guidance, feedback coordination, and ongoing revisions as features and workflows changed.
Result / learning
The completed Articulate training was shared with stakeholders after recommended edits were incorporated. The work reinforced the value of modular resources that can be revised without rebuilding an entire experience.

03

Design systems + performance support

Training Design System

Audience / context
Training Pod contributors building mentor-readiness experiences for new program launches.
Problem
Each launch needed program-specific content without rebuilding the development process from scratch.
My contribution
Developed reusable structures and standards across source verification, learning architecture, Rise design, accessibility, knowledge checks, QA, and publication preparation.
Result / learning
The current BSAIIO and BSAISEC builds are using the model simultaneously, making it easier to see what should be standardized and what must remain program-specific.
